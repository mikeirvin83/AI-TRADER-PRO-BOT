# Trading Intelligence Dashboard

## Project Overview
Real-time trading intelligence dashboard for an autonomous algorithmic trading platform. Phase 10 frontend that connects to a FastAPI backend at http://localhost:8000.

## Technical Architecture
- Dark-themed dashboard with near-black background (#0a0a0f), navy accents, electric blue highlights
- 7 pages: Dashboard (/), Strategies, Research, Risk Monitor, Market Intel, Trade History, System Control
- Left sidebar navigation, persistent status bar with kill switch
- API proxy at /api/proxy to avoid browser CORS issues when connecting to FastAPI backend
- Mock data fallback when backend is unavailable (MOCK indicator shown)
- Auto-refresh every 5 seconds for live data panels
- Auth: NextAuth.js v4 with credentials provider, JWT sessions

## Color Palette
- Background: #0a0a0f (near-black)
- Card: #12121a
- Border: #1e1e2e
- Electric Blue: #3b82f6 (primary actions, active states)
- Green: #22c55e (gains, positive)
- Red: #ef4444 (losses, risk, destructive)
- Amber: #f59e0b (warnings)
- Purple: #a855f7 (knowledge, research)

## Key Patterns
- All pages use DashboardShell (sidebar + status bar + main content)
- Data fetching via useApiPolling hook with configurable interval
- Server components for page shells, client components for interactive panels
- DataBadge component for all status/direction/severity badges
- MetricCard for key metrics display
- MockIndicator shows when using simulated data

## Database
- Simple User model for authentication only
- Trading data comes from FastAPI backend, not from dashboard DB

## Backend Connection
- FastAPI at http://localhost:8000
- All frontend API calls go through /api/proxy server route
- Returns {_mock: true} when backend unavailable, triggering mock data fallback
